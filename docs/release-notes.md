# Draft release notes — v1.0.0

**Status: DRAFT ONLY. No tag or GitHub release has been created.**

## Features

- Java/Maven console program to add and alphabetically list reptiles and arachnids.
- Abstract `Pet` domain, two concrete subclasses, and Factory design pattern.
- Input validation, custom domain exception, save/load persistence and JUnit tests.
- UML, user stories, design choices and usage documentation.

## Known limitations

- Only reptile and arachnid categories; no edit/delete operations.
- Local Java serialization, designed only for trusted local data.
